# کپچای عددی فارسی (Farsi Numeric Captcha)

یک افزونه سبک و کاملاً فارسی برای گذاشتن کپچای تصویری ساده روی **فرم نظرات وردپرس** — همان تجربه‌ای که در تصویر فرستاده‌شده دیده می‌شود: چند رقم روی یک تصویر کوچک که کاربر باید وارد کند.

بدون سرویس بیرونی، بدون API، بدون جمع‌آوری داده، و بدون کند کردن سایت.

---

## ✨ ویژگی‌ها

- **کپچای تصویری عددی** با ۳ تا ۶ رقم (پیش‌فرض ۴ رقم) و تصویر PNG که با کتابخانه GD ساخته می‌شود.
- **ارقام فارسی یا لاتین** — قابل انتخاب در تنظیمات (۳ ۸ ۴ ۲ یا 3842).
- **هر دو نوع ورودی پذیرفته می‌شود**: کاربر می‌تواند با ارقام فارسی (`۳۸۴۲`)، عربی (`٣٨٤٢`) یا لاتین (`3842`) پاسخ دهد. فاصله‌های اضافه هم نادیده گرفته می‌شود.
- **دکمه «تصویر جدید»** (بدون بارگذاری دوباره صفحه) با AJAX.
- **خوانا و ساده**: نویز در سه سطح (کم / متوسط / زیاد)، ارقام ۰ و ۱ حذف شده‌اند تا با حرف‌های O و I اشتباه نشوند.
- **محدودسازی تلاش‌ها**: پس از تعداد مشخصی پاسخ اشتباه، آن بازدیدکننده چند دقیقه مسدود می‌شود.
- **کد یک‌بارمصرف و منقضی‌شونده** (پیش‌فرض ۱۵ دقیقه) و ذخیره‌شده در Transient (نه در کوکی و نه در فیلد مخفی).
- **سازگار با صفحه‌های کش‌شده** (توکن داخل فرم و کد سمت سرور است).
- **کاربران واردشده معاف** هستند (قابل تغییر). مدیران و ویرایشگران همیشه معاف‌اند.
- **قابل فعال‌سازی برای** فرم نظرات، صفحه ورود، ثبت‌نام و بازیابی رمز عبور.
- **بدون فایل اضافی سمت کاربر** جز یک CSS و یک JS بسیار کوچک (~۲ کیلوبایت) که فقط در صفحات لازم بارگذاری می‌شوند.
- **راست‌به‌چپ** و هماهنگ با ظاهر پیش‌فرض وردپرس و بیشتر پوسته‌ها.
- ترجمه‌پذیر (Text Domain: `farsi-numeric-captcha`).

## 📦 نصب

1. فایل `farsi-numeric-captcha.zip` را از پیشخوان وردپرس نصب کنید:
   **افزونه‌ها → افزودن → بارگذاری افزونه → انتخاب فایل → نصب → فعال‌سازی**
   (یا پوشه `farsi-numeric-captcha` را با FTP در `wp-content/plugins/` قرار دهید.)
2. به **تنظیمات → کپچای فارسی** بروید و تنظیمات دلخواه را اعمال کنید.
3. یک نوشته را باز کنید و بخش دیدگاه را ببینید؛ کپچا به‌طور خودکار زیر فیلدهای نظر نمایش داده می‌شود.

> **پیش‌نیاز:** افزونه PHP `gd` روی سرور فعال باشد (تقریباً همه هاست‌های وردپرسی دارند). اگر فعال نباشد، افزونه در پیشخوان هشدار می‌دهد.

## ⚙️ تنظیمات (تنظیمات → کپچای فارسی)

| بخش | گزینه‌ها |
|---|---|
| محل نمایش | فرم نظرات، فرم ورود، ثبت‌نام، بازیابی رمز، عدم نمایش برای کاربران واردشده |
| ظاهر تصویر | تعداد ارقام، عرض/ارتفاع، اندازه فونت، میزان نویز، رنگ پس‌زمینه و رنگ ارقام، شکل ارقام (فارسی/لاتین) |
| متن‌ها و امنیت | برچسب فیلد، متن راهنما، تعداد تلاش مجاز، مدت مسدودی، مدت اعتبار کد |

در بالای همین صفحه یک **پیش‌نمایش زنده** از تصویر با تنظیمات فعلی می‌بینید.

## 🧩 سازگاری با پوسته‌ها و فرم‌سازها

افزونه به قلاب‌های استاندارد وردپرس وصل می‌شود:

- `comment_form_after_fields` و `comment_form_logged_in_after` → فرم نظر
- `pre_comment_on_post` → اعتبارسنجی سمت سرور
- `login_form` / `authenticate` → صفحه ورود
- `register_form` / `registration_errors` → ثبت‌نام
- `lostpassword_form` / `lostpassword_post` → بازیابی رمز

اگر پوسته یا فرم‌ساز شما از `comment_form()` استاندارد استفاده کند، کپچا خودکار نمایش داده می‌شود.

### استفاده دستی در هر فرمی

اگر خواستید فیلد کپچا را جای دیگری بگذارید:

```php
<?php FNC_Forms::render_field(); ?>
```

و در محل پردازش فرم:

```php
$check = FNC_Captcha::verify( $_POST['fnc_token'], $_POST['fnc_code'] );
if ( ! $check ) {
    // پیام خطا
}
```

## 🎨 تغییر ظاهر

- از تنظیمات افزونه: اندازه تصویر، رنگ‌ها، نویز و اندازه فونت.
- با فیلتر `fnc_image_url` می‌توانید آدرس تصویر را عوض کنید.
- با فیلتر `fnc_font_candidates` می‌توانید فونت دیگری برای ارقام معرفی کنید:

```php
add_filter( 'fnc_font_candidates', function ( $fonts ) {
    array_unshift( $fonts, get_stylesheet_directory() . '/fonts/Vazirmatn-Bold.ttf' );
    return $fonts;
} );
```

فونت پیش‌فرض `DejaVu Sans Bold` است (مجوز آزاد، در `assets/fonts/` همراه افزونه).

## 🔐 نکته‌های امنیتی

- کد در دیتابیس/Transient نگه‌داری می‌شود و در HTML یا کوکی قرار نمی‌گیرد.
- مقایسه کد با `hash_equals` (مقاوم به حملات زمانی) انجام می‌شود.
- توکن با `random_bytes` ساخته می‌شود و پس از پاسخ درست باطل می‌شود.
- تعداد تلاش‌ها بر اساس IP محدود می‌شود تا حملهٔ حدس زدن کد ممکن نباشد.
- داده‌ای به بیرون ارسال نمی‌شود و کوکی اضافه‌ای ساخته نمی‌شود.

## ❓ پرسش‌های رایج

**کپچا در فرم نظر نمایش داده نمی‌شود.**
مطمئن شوید در تنظیمات، «فرم نظرات» تیک خورده و برای نوشته‌ای که آزمایش می‌کنید، دیدگاه‌ها باز است. اگر با کاربر واردشده‌اید و «عدم نمایش برای کاربران واردشده» فعال است، خارج شوید یا آن گزینه را بردارید.

**تصویر نمایش داده نمی‌شود.**
کتابخانه GD روی سرور فعال نیست یا `admin-ajax.php` توسط افزونه امنیتی مسدود شده است.

**می‌خواهم سخت‌گیرانه‌تر باشد.**
تعداد ارقام را ۵ یا ۶ کنید و نویز را روی «زیاد» بگذارید.

**با کش صفحه مشکلی ندارد؟**
نه. توکن در خود فرم چاپ می‌شود و کد سمت سرور نگه‌داری می‌شود؛ اما اگر از کش کامل صفحه (Full Page Cache) استفاده می‌کنید، بهتر است مدت اعتبار کد را بیشتر از مدت کش بگذارید (مثلاً ۳۰ دقیقه).
